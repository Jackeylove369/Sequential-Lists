# 顺序表（Sequential List）教学程序

> 一份用于备考 **408 计算机学科专业基础综合** 的顺序表入门程序，
> 重点讲解「下标」与「位序」的关系，以及顺序表的基本操作。

---

## 一、这是一个什么程序

本程序用 C 语言实现了**顺序表**（线性表的顺序存储结构），并围绕顺序表
最核心的概念——**下标（index）**——展开讲解。

顺序表本质就两样东西：

```c
typedef struct {
    int data[MaxSize];  // 一段连续内存，存元素
    int length;         // 当前元素个数
} SqList;
```

程序通过可视化的方式（打印「下标 vs 位序 对照表」），帮你直观理解：

| 位序（第几个） | 下标（data[...]） |
|--------------|------------------|
| 第 1 个 | data[0] |
| 第 2 个 | data[1] |
| 第 3 个 | data[2] |
| 第 n 个 | data[n-1] |

**核心换算关系：下标 = 位序 - 1**

## 二、函数清单（重点：408 要写哪些）

程序里的函数分为两类：**「考试要写的」** 和 **「教学辅助的」**。

### ✅ 408 考研需要掌握并手写的函数（核心）

| 函数 | 作用 | 时间复杂度 | 考试要求 |
|------|------|-----------|---------|
| `GetByIndex` | 按下标取值（随机存取） | O(1) | 会写 |
| `GetByPos` | 按位序取值（位序→下标 -1） | O(1) | 会写 |
| `InsertByIndex` | 按下标插入（元素后移） | O(n) | **必会** |
| `DeleteByIndex` | 按下标删除（元素前移） | O(n) | **必会** |
| `FindByValue` | 按值查找（返回下标） | O(n) | 会写 |

> 这 5 个函数是 408 代码题的基础，尤其是**插入、删除**（涉及元素搬移），
> 是历年手写代码题的根基，务必能脱稿默写。

### 📎 教学辅助函数（考试不要求，理解用）

| 函数 | 作用 |
|------|------|
| `InitList` | 初始化（长度清零） |
| `Print` | 打印整表（下标+元素对齐显示） |
| `ShowIndexRule` | 打印「下标 vs 位序」对照表，帮助理解换算 |

> 考试手写时，`Print`、`ShowIndexRule` 这类辅助函数**不需要写**，
> 但 `InitList`（或直接在结构体定义时初始化）通常要体现。

## 三、关键点：程序需要 .exe 可执行文件才能运行

**`.c` 文件是源代码，不能直接双击运行**，必须先编译成 `.exe` 可执行文件。

### 生成 .exe 的方法

**方法 1：用 Visual Studio（推荐）**

1. 打开 Visual Studio → 创建「空项目」
2. 在「源文件」中添加本 `.c` 文件
3. 点「本地 Windows 调试器」（绿色 ▶）或菜单「生成 → 生成解决方案」
4. 编译成功后，`.exe` 位于项目目录下的 `Debug\` 或 `Release\` 文件夹里
5. 双击该 `.exe` 即可运行

**方法 2：用命令行（gcc / MinGW）**

```bash
gcc 顺序表下标讲解_修正版.c -o 顺序表.exe
./顺序表.exe
```

**方法 3：用 Dev-C++**

1. 打开 `.c` 文件 → 点「编译并运行」（F11）
2. 会在同目录生成同名 `.exe`

### 为什么需要 .exe

- `.c` 是给**人看的源代码**（文本文件），机器不认
- `.exe` 是给**机器执行的二进制程序**，由编译器把 `.c` 翻译而成
- 程序里用到的 `printf` 等函数，编译时会被链接进 `.exe`，运行 `.exe` 才能在屏幕上输出结果

## 五、配套建议

1. 先读懂 `下标 = 位序 - 1` 这个换算
2. 重点手写 `InsertByIndex` 和 `DeleteByIndex`，体会循环方向：
   - **插入 = 从后往前搬**（`j` 从大往小）
   - **删除 = 从前往后搬**（`j` 从小往大）
3. 之后可延伸到 408 真题：循环左移、求交集、主元素等
